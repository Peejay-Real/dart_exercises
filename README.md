## Program Description

This program simulates a student payment center.
It displays the student's name, number of payments,
second payment due, amount paid, remaining balance,
and payment status.

It demonstrates Dart variables, data types, arithmetic
operators, comparison operators, and console output.

## How to Run

Open the project folder in a terminal and run:

    dart run
